## Phase 1 — Keyword search in the terminal

**Built:** shared tokenizer (lowercase, accent folding, own Porter stemmer), in-memory inverted index
(flat int arrays: doc IDs, freqs, positions), BM25 (k1 = 1.2, b = 0.75), AND via two-pointer intersection
(shortest list first) with an OR fallback, size-10 min-heap, terminal CLI (`sift-cli`).
**Stop words** (33-word Lucene list) are **kept in the index**. At query time they are dropped only if a
non-stop word remains.

**Tests:** 93 JUnit tests pass. They include all 23,531 words of Porter's official reference list, and
"to be or not to be", "the who" and "the history of india".

## Phase 1 ranking fixes (done 2026-11-11, ranking locked until Phase 6)

**Final default ranking:** `BM25(body, b = 0.3) + 2 × BM25(title, b = 0.75)`, k1 = 1.2, AND with OR fallback,
question words (who/what/when/where/why/how/did/does/is) dropped at query time. No alias bonus.

| Step (main 50 queries, frozen before tuning) | MRR | Decision |
| --- | --- | --- |
| Baseline BM25 | 0.275 | |
| BM25F grid, best w = 5, b_body = 0.5 | 0.635 | lost to the sum |
| Sum grid (w ∈ {2,3,5,8} × b ∈ {0.3,0.5,0.75}), best **w = 2, b = 0.3** | 0.799 | chosen (on the grid edge; not extended) |
| Alias field from redirects, w_alias 1 / 2 | 0.801 / 0.790 | not adopted (+0.002 < 0.01 rule) |
| (a) question stop words / (b) soft AND / (c) both | **0.815** / 0.801 / 0.815 | (a) chosen (simplest of the tie) |

## Open issues
- **32.11% of links reach no article, even after following redirects** (re-measured 2026-11-11
  with redirect chains resolved from `redirects.jsonl`):
  - 32.06%: target is neither an article nor a redirect. These are "red links" (titles that only
    exist on English Wikipedia) and links to skipped disambiguation pages.
  - 0.05% (3,183 links): target is a redirect whose final target is not an article.
    1,822 of the 115,575 redirects end at a non-article, mostly disambiguation pages.
  - Redirect chains are rare: exactly 1 link needed 2+ hops. No redirect loops were found.

  This is real data, not a parser bug (only 0.3% would match if case were ignored).
  PageRank (Phase 4) must follow redirects and then drop links whose final target is not an article.
- **Ranking weak spots left after the fixes** (see `docs/learning/phase-1.md`):
  questions whose answer is not named in the query (held-out MRR 0.048) → Phase 5 Smart search;
  redirect-only abbreviations ("usa" #2,091, "uk" #222) → retry the alias field in Phase 6;
  "world war 2" shows *Guild Wars 2* first, *World War II* #5.
- **The final MRR is tuned on the 50 main queries.** Report the held-out number (0.697) next to it. In Phase 6,
  write a fresh held-out set before any new tuning: the current 20 have now been looked at once.
- ~~Run the CLI on Java 21~~ **Fixed 2026-11-11:** `scripts/sift-cli` runs the CLI on Gradle's Java 21; the CLI warns on any other version.
- **3,496 of 280,748 articles (1.25%) keep a little markup** (any of `[[ ]] {{ }} | < '' ==`), mostly
  from broken source wikitext or articles that show markup as examples. This is acceptable: the
  tokenizer splits on non-letters anyway. It is an upper bound, because a `|` can be legitimate text.
- **Many short articles:** the median is 72 words. Confirmed in Phase 1: length normalisation strongly
  favours short articles (see the ranking issue above).
- Links found inside `<ref>` citations are kept in `links` (the citation *text* is removed).
  This has a minor effect on PageRank. Revisit only if PageRank looks odd.

## Notes for later
- **Memory / hosting (Phase 5–7):** 280,748 vectors × 384 dims × 4 bytes ≈ 431 MB for vectors alone.
  If memory is tight, use **int8 quantization** (1 byte per number instead of 4, about 4× smaller).
  Measure recall before and after. Render's free tier (512 MB) likely cannot hold the full index.
- **Store article text for snippets (Phase 2):** the doc table must keep the text (or an
  offset/length into a text file), not just title and length, so highlighted snippets can be built
  at query time.
- **Write and freeze the 50 eval queries before Phase 4 tuning:** this keeps MRR honest (no picking
  queries we already do well on). Commit `eval/queries.json` before tuning α or PageRank.
- **CC BY-SA credit line** on the website footer and in the README:
  "Content from Simple English Wikipedia, licensed under CC BY-SA 4.0."
  (Already in README.md; the website still needs it in Phase 3.)
